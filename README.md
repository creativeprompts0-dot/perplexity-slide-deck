# Perplexity Insights Pro

Crie um site de uma página estilo "apresentação/slide deck" em português, moderno e elegante, sobre a ferramenta de IA Perplexity, para uma apresentação de faculdade/curso sobre IA aplicada a pequenos negócios.

Design: dark mode elegante, com detalhes em roxo/turquesa (cores da Perplexity), tipografia grande e moderna, muito espaço em branco, transições suaves ao rolar, cada seção ocupando a tela cheia como um "slide".

Seções (nessa ordem):

1. Hero: título "Perplexity AI" + subtítulo "O motor de respostas que pesquisa, cita e decide com você"

2. O que é: explicação curta de como funciona (busca na web ao vivo + resposta com citações)

3. Principais recursos: cards para Pro Search, Deep Research, Spaces, Model Council, navegador Comet

4. Aplicações por nicho de negócio: 3 cards lado a lado, cada um com ícone, nome do nicho, problema e como a Perplexity ajuda:

   - Alimentação (padaria/cafeteria/hamburgueria): tendências de cardápio e preços da concorrência

   - Moda e vestuário: tendências de estação e análise de concorrentes

   - Serviços de beleza (salão/barbearia): plano de conteúdo para redes sociais

5. Demonstração prática: espaço para eu inserir 3 prints/screenshots dos meus prompts testados, com legendas editáveis

6. Caso real: seção para descrever o negócio real usado no estudo de caso, com espaço para "problema", "como a IA ajudou" e "resultado"

7. Uso responsável: bloco de alerta destacando que respostas da IA devem ser sempre conferidas, citando limitações reais (a IA pode interpretar mal uma fonte)

8. Encerramento: a pergunta "Se você tivesse apenas este recurso de IA e um pequeno negócio local, como usaria essa ferramenta amanhã?"

Use ícones, gradientes sutis e componentes bem construídos, sem parecer template genérico. use essas fotos q te mandei como referencia ´para esse trabalho. use tawind css deixe o site binito
